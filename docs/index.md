# Unknown Robot2

Unknown Robot2 is a ROS 2 Jazzy autonomous mobile robot simulation project using Gazebo Harmonic, Nav2, SLAM Toolbox, RViz2, and ArUco marker docking.

## Project Overview

This project simulates an autonomous ground robot in Gazebo Harmonic with ROS 2 Jazzy. The robot can perform mapping, localization, autonomous navigation, obstacle avoidance, and docking experiments using ArUco markers.

## Features

- ROS 2 Jazzy mobile robot simulation
- Gazebo Harmonic robot model and world
- Nav2 autonomous navigation
- SLAM Toolbox mapping
- AMCL localization
- RViz2 visualization
- Laser scan obstacle detection
- Odometry and TF integration
- ArUco marker docking support
- Custom Gazebo world for navigation testing

## Main Technologies

- ROS 2 Jazzy
- Gazebo Harmonic
- Nav2
- SLAM Toolbox
- AMCL
- RViz2
- ArUco marker detection
- Python
- Xacro / URDF
